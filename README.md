### 🚀 Featured DevOps Project: [AWS Three-Tier Infrastructure with Terraform](https://github.com)

An automated, modular AWS infrastructure deployment built with **Terraform**, translating enterprise network segmentation and zero-trust security principles into reusable cloud modules:

* **Multi-AZ Three-Tier VPC (`modules/three-tier-network`):** Designed a 6-subnet VPC architecture (`2 AZs x 3 Tiers`) separating Public (ALB/NAT), Private (App), and Isolated (RDS/Aurora) tiers with dynamic CIDR calculation.
* **Zero-Trust Security Group Chaining:** Enforced strict tier-to-tier traffic rules (`Internet -> public_sg -> private_sg -> isolate_sg`) modeled after enterprise firewall policies.
* **Cost & High-Availability Controls:** Built a `single_nat_gateway` toggle to optimize Dev/UAT lab costs while supporting full multi-AZ NAT redundancy in Production.
